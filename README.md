Aplicativo de abertura de chamados e fechamentos exemplos SLA.
Esse App foi feito utilizando linguagem de programação HTML5, PHP, Bootstrap5, MySQL e Js.
Para funcionar recomendo que abaixe o aplicativo XAMPP para simular um servidor WEB e o banco de dados, pois a aplicação foi feita nesse ambiente de teste.

Link do XAMPP: https://www.apachefriends.org/download.html
